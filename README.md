# YouTube Focus Filter

A Firefox extension that blocks YouTube videos unrelated to what you want to focus on. You list the topics you care about, and every video card on YouTube is scored against them by a small embedding model ([all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2)) running entirely on your device. Videos that don't match get blurred and made unclickable, or hidden entirely.

No data leaves your browser: the model and runtime are bundled with the extension and it never makes network requests.

## How it works

1. The content script finds video cards on the page (home feed, sidebar, search, Shorts, playlists, and the mobile site) and pulls out each title.
2. The background script embeds the titles and your focus topics with MiniLM (via [transformers.js](https://github.com/huggingface/transformers.js) + ONNX Runtime WASM).
3. Each title's score is its highest cosine similarity to any of your topics. Each topic is embedded both as written and as "a video about &lt;topic&gt;", which helps short topics match full titles.
4. Titles scoring below the strictness threshold are blocked.

Title embeddings are cached (up to 5,000), so changing your topics re-scores the page quickly.

## Setup

Requires Node.js 18+ and Firefox 128+.

```sh
npm install
npm run setup   # copies transformers.js + ONNX WASM into extension/vendor, downloads the model into extension/models
```

`extension/vendor/` and `extension/models/` are gitignored, so run `npm run setup` after cloning.

## Running

```sh
npm start       # launches a temporary Firefox profile with the extension loaded, opened to YouTube
```

Or load it manually: open `about:debugging#/runtime/this-firefox`, click **Load Temporary Add-on**, and pick `extension/manifest.json`.

## Using it

Click the toolbar icon to open the popup:

- **What do you want to focus on?**: one topic per line, then **Save focus** (or Cmd/Ctrl+Enter). Several specific lines work better than one broad one, e.g. `deep learning and neural networks` instead of `AI`. With no topics, nothing is filtered.
- **Strictness**: the similarity threshold (0.05 to 0.60, default 0.25). Higher blocks more.
- **Unrelated videos**:
  - *Blur*: the thumbnail, title, and metadata are blurred, and the card can't be clicked.
  - *Hide entirely*: the card is removed from the page.
- **Blur thumbnails while analyzing**: blur cards until they've been scored, so you don't glimpse anything first.
- **Filter search results too**: turn off to leave `/results` pages unfiltered.
- **Show similarity scores**: debug badge on each card (green = allowed, red = blocked); hover for the full score and threshold.
- **Test a title**: paste any title to see its score and whether it would be blocked.

## Tuning the threshold

`npm run calibrate` scores a fixed set of sample titles against topics you pass in, using the same model and scoring as the extension:

```sh
npm run calibrate -- "machine learning" "calculus"
```

Use the output to pick a strictness that separates the titles you want from the ones you don't.

## Project layout

```
extension/
  manifest.json      Firefox MV3 manifest
  background.js      loads the model and scores titles
  scoring.js         topic expansion + cosine scoring (shared with calibrate)
  content.js         finds video cards and tags them allowed/blocked/pending
  content.css        blur / hide / score-badge styles
  defaults.js        default settings
  popup/             settings popup
  vendor/            transformers.js + ONNX Runtime (generated by setup)
  models/            MiniLM model files (generated by setup)
scripts/
  setup.mjs          vendors the runtime and downloads the model
  calibrate.mjs      prints scores for sample titles
```
